# AI controls, robots.txt and llms.txt audit — 2026-08-22

Trigger: Search Console **AI controls → Search generative AI** was switched to
**Include** on 2026-08-22, and robots.txt last showed as fetched/valid on
2026-08-16. This note records what was checked and what changed.

## Search generative AI = Include

Nothing in the codebase contradicts the setting:

- `app/robots.ts` allows `/` for `*` and disallows only `/api/`, so Googlebot —
  the crawler that feeds AI Overviews and AI Mode — has full access to every
  content route.
- No page emits `nosnippet`, `max-snippet`, `noarchive`, `data-nosnippet` or a
  `noai` style directive; a snippet cap would have limited generative surfaces
  even with the control set to Include.
- `Google-Extended` is separately allowed. That token governs Gemini app
  grounding and Vertex AI training, not AI Overviews, so the two controls are
  consistent rather than redundant.

No robots.txt change was needed.

## robots.txt

Generated by `app/robots.ts` at build time:

- `User-agent: *` → `Allow: /`, `Disallow: /api/`.
- Same rule repeated for 11 named AI crawlers: GPTBot, ChatGPT-User,
  OAI-SearchBot, ClaudeBot, Claude-Web, anthropic-ai, PerplexityBot,
  Perplexity-User, Google-Extended, Applebot-Extended, CCBot.
- Declares `/sitemap.xml` and `/image-sitemap.xml`.

Verdict: valid and correctly permissive. Matches the "Valid" status Search
Console reported on 2026-08-16.

## llms.txt — drift found and fixed

`public/llms.txt` is hand-maintained, while `/llms-full.txt` is generated from
`data/*.json` via `lib/seo/llms-full.ts`. The curated file had fallen behind:
it listed **36 of 63** live calculators. The 27 missing ones came from the
cluster files added between 2026-08-05 and 2026-08-11
(`decision-tools-2026.json`, `insurance-tools-2026.json`,
`investing-tools-2026.json`, `lifestage-tools-2026.json`), which the coverage
check never read.

Fixed in this change:

- Added all 27 missing live calculators (rent vs buy, home affordability,
  rental yield, rent agreement stamp duty, job offer, increment, bonus tax,
  car loan, two-wheeler loan, education loan, debt snowball, credit-card
  minimum due, credit card vs personal loan, term life cover, health cover
  adequacy, SGB vs physical gold, index vs active cost, ELSS vs 80C, NPS Tier 2
  vs MF, XIRR, Rule of 72, FIRE, OPS vs NPS, SCSS, POMIS, child education,
  wedding planner).
- Added the hub pages that were absent: `/start-here`, `/money-health-check`,
  `/nri`, `/financial-updates`, `/government-salary-updates`, `/resources`.
- Refreshed the `Last updated` stamp to 2026-08-22, and
  `LLMS_CATALOG_LAST_REVIEWED` in `lib/seo/llms-full.ts` from 2026-07-16 to
  2026-08-22 (the catalog body was already current — it is derived from live
  data — only the stamp was stale).
- `scripts/validate-ai-seo-readiness.mjs` now reads all six calculator source
  files instead of two, so any future cluster file is covered, and it also
  fails if llms.txt links a consolidated (301-redirected) slug.

Guide count (34) already matched `data/calculator-guides.ts`, and
`validate-internal-links.mjs` confirms all 63 live tools are in the sitemap —
the gap was llms.txt only.
